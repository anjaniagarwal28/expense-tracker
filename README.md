# 💰 Expense Tracker with Budget Insights

A web-based Expense Tracker developed using React.js and Firebase.  
The application helps users manage their income, expenses, monthly budgets, and financial reports.

## 🚀 Features

- 🔐 User Login & Signup
- 🔑 Forgot Password
- 💰 Add Income
- 💸 Add Expenses
- 🏷️ Expense Categories
- ✏️ Edit Transactions
- 🗑️ Delete Transactions
- 🔎 Search Transactions
- 📅 Monthly Transaction Filter
- 💵 Monthly Budget Management
- 📊 Expense by Category Chart
- 📈 Monthly Income vs Expense Chart
- 📊 Financial Summary Chart
- 💡 Budget Insights
- 📋 Monthly Financial Report
- 📥 CSV Export
- 📄 PDF Financial Report
- 📱 Responsive Mobile Design
- 🔥 Firebase Authentication
- ☁️ Firebase Firestore Database

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- HTML
- CSS

### Database & Authentication
- Firebase Authentication
- Firebase Firestore

### Charts
- Chart.js

### Additional Libraries
- PapaParse
- jsPDF
